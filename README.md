# Halloween 안전 놀이터

초등학생을 위한 할로윈 문화·인파 안전 학습 웹앱입니다. 학년군별 짧은 그림 이야기와 질문, 호박등 만들기, 서로 다른 축제 문화 살펴보기, 안전 상황 판단, 옷차림 이유 설명, 생각 확인과 학습 결과지를 제공합니다. 브라우저에서 작동하며 학습 기록은 기본적으로 이 기기의 로컬 저장소에 남습니다.

## 실행

- GitHub Pages: `main`에 푸시하면 `.github/workflows/pages.yml`이 저장소 루트의 정적 파일을 배포합니다.
- 다른 정적 호스팅: `index.html`, `app.js`, `styles.css`, `sw.js`, `manifest.json`, `icon.svg`, `404.html`을 같은 폴더에 배치합니다.
- 인터넷 없는 단일 파일: `halloween_edu_app.html`을 브라우저에서 엽니다. 로컬 파일 실행 시 서비스 워커는 사용하지 않습니다.
- 로컬 개발: `npm ci`, `npm run build`, 정적 HTTP 서버로 루트 폴더를 제공합니다. `npm run check`는 Chromium 브라우저 흐름과 오프라인 재접속을 검사합니다.
- 검사 환경에 Chrome이 없으면 `npx playwright install chromium`으로 테스트 브라우저를 준비합니다. 필요하면 `CHROME_PATH`로 실행 파일 위치를 지정합니다.

`src/`가 편집 원본입니다. `npm run build`가 배포용 `index.html`, `app.js`, `styles.css`, `sw.js`, `halloween_edu_app.html`을 생성합니다. 생성 파일을 직접 수정하면 다음 빌드에서 덮어쓰입니다. 캐시 버전은 빌드 내용의 해시로 생성됩니다.

화면 본문과 제목, 버튼, 결과 이미지에 Gowun Dodum 글꼴을 사용합니다. 글꼴을 번들로 포함해 오프라인에서도 동일하게 표시합니다. SIL OFL 라이선스는 `licenses/gowun-dodum-OFL.txt`에 있습니다.

## 수업 사용

첫 화면에서 학년군을 고르고 수업을 시작합니다. 문화 이야기 → 안전한 선택 → 배려하는 옷차림 → 생각 정리 순으로 이어지며, 배움 기록은 마지막에 확인합니다. 호박등 꾸미기, 안전 게임, 옷차림 꾸미기는 각 단계의 ‘더 해보기’에 있습니다. 상단의 ‘설정·활동 이동’에서 학년 변경, 단계 이동, 글씨·소리 설정, 교사 안내를 열 수 있습니다.

교사 안내에서 학년군, 수업 시간, 테마, 시작 활동과 필수 활동을 설정합니다. 공유 URL과 QR 코드는 이 설정을 담습니다. 참여 확인서는 선택한 필수 활동을 끝낸 뒤, 안전 대장 임명장은 안전 핵심 목표 6개를 각각 후속 질문으로 확인한 뒤 내려받을 수 있습니다. 배움 기록 화면에서 ‘설정·활동 이동’을 열면 결과지·참여 확인서·기록 JSON 도구가 나타납니다. 기록 JSON은 이 기기에서 내려받고 가져올 수 있습니다. 여러 학생의 파일을 선택하면 각 학생의 요약을 로컬에서 확인합니다.

안전 게임은 넓은 길 선택과 이동 판단을 연습합니다. 가슴 앞 공간 확보는 혼잡 속 호흡을 위한 행동을 설명하며, 장애물 충돌을 무효화하는 능력으로 표현하지 않습니다. 실제 긴급 상황에서는 교사·보호자·현장 안내에 따르고 112 또는 119에 연락합니다.

## 개인정보와 오프라인

이 앱에는 자체 서버나 데이터베이스가 없습니다. 이름과 학급, 학습 기록은 브라우저 저장소와 사용자가 내려받은 파일에만 들어갑니다. 공유 URL에는 교사 수업 설정만 들어갑니다. HTTPS 또는 localhost에서 첫 접속이 완료되면 서비스 워커가 핵심 정적 파일을 캐시하여 재접속 때 사용할 수 있습니다. 새 배포가 설치되면 열려 있던 탭을 닫은 뒤 다시 열어 새 버전을 적용합니다.

기존 `halloween_edu_progress_v1` 원문은 삭제하지 않고, 학년·스탬프·점수를 새 회차와 구분해 표시합니다. 손상된 v2 기록은 자동 덮어쓰지 않습니다. 이 상태에서 사용자가 새 수업을 명시적으로 시작하면 손상된 원문을 별도 키에 보존한 뒤 새 기록을 만듭니다.

학년별 이야기와 퀴즈 내용이 바뀐 버전으로 처음 접속하면 기존 v2 원문을 `halloween_edu_progress_v2_before_content_…` 키에 백업합니다. 이야기·퀴즈 진행은 새 내용에 맞춰 다시 시작하고, 변경되지 않은 안전 활동 기록과 옷차림 활동은 유지합니다. 백업 저장에 실패하면 기존 기록을 덮어쓰지 않습니다.
